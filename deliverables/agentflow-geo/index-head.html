AgentFlow — 开源零代码 AI Agent 平台

拖拽式工作流编辑器 + 多模型热切换 + 知识库 RAG + Skill 广场 + 一键部署。 默认 SQLite 单机可跑，用户、对话与知识库数据全部自托管。

核心能力

  • 拖拽式工作流编辑：ReactFlow 画布，触发器 / LLM / 知识库 / 工具 / 条件分支 / 回复六类节点自由组合
  • 多模型热切换：任意 OpenAI 兼容端点（OpenAI、Anthropic、DeepSeek、通义、Ollama），界面改完不用重启
  • 知识库 RAG：文档自动分块入库，向量检索返回相关度，向量模型与对话模型分开配置
  • Skill 广场：23 个预置技能（Excel、PPT、PDF、学术检索、会议纪要、统计分析等）
  • 模板市场：客服 / 销售 / HR / 财务场景模板，一键套用为可用 Agent
  • 产物交付：生成文件可下载，图片类产物在对话内联渲染

技术栈

前端 React 18 + TypeScript + Vite + ReactFlow；后端 Python 3.11+ / FastAPI + SQLAlchemy 2.0（async）；默认 SQLite，可选 PostgreSQL + pgvector；Docker Compose 部署。
